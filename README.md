# CafeBoostAI

CafeBoostAI is an AI-powered website analysis platform built for the Anakin Buildathon.

## Features

- Website scraping using Anakin Wire
- AI-powered analysis using Google Gemini
- SEO scoring
- UX scoring
- Business scoring
- Missing feature detection
- Improvement recommendations
- Raw HTML download
- PDF report download

## Tech Stack

- Python
- Flask
- HTML/CSS/JavaScript
- Google Gemini API
- Anakin Wire API

## How It Works

1. User submits a website URL.
2. Anakin Wire scrapes the website.
3. Gemini analyzes the content.
4. CafeBoostAI generates actionable recommendations.
